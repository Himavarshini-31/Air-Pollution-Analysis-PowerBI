# 🌍 Air Pollution Analysis Dashboard – India

## 📌 Project Overview
An interactive Power BI dashboard developed to analyze air pollution patterns across 26 Indian cities using Air Quality Index (AQI) data from 2015 to 2020.

The project focuses on identifying pollution hotspots, analyzing AQI trends, comparing pollutant levels, and understanding air quality distribution across different cities.

## 🎯 Project Objectives
- Analyze air quality trends across Indian cities.
- Identify cities with higher average AQI.
- Understand the distribution of AQI categories.
- Compare different air pollutants.
- Explore geographical patterns in air pollution.

## 📊 Dashboard Features
- **KPI Cards:** Average AQI, Total Cities, and Total Pollution Records.
- **AQI Trend Analysis:** Track changes in air quality over time.
- **City-wise Analysis:** Identify the most polluted cities.
- **AQI Category Distribution:** Analyze different air quality categories.
- **Pollutant Comparison:** Compare PM2.5, PM10, NO2, SO2, CO, and NH3.
- **Geographical Analysis:** Visualize pollution distribution across India.
- **Interactive Filters:** Filter data by city, year, and AQI category.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Cleaning and Transformation

## 📈 Key Insights
- Analyzed air quality records across 26 Indian cities.
- Identified cities with higher average AQI levels.
- Examined changes in AQI over the period 2015–2020.
- Compared particulate matter and gaseous pollutant measurements.
- Explored the distribution of air quality categories.

## 🧹 Data Preprocessing
Used Power Query to:
- Handle missing and invalid values.
- Replace text-based missing values with null.
- Convert pollutant columns into appropriate numeric data types.
- Format date columns.
- Remove records with missing AQI values.

## 📂 Dataset
**Source:** Kaggle – Air Quality Data in India

Dataset: https://www.kaggle.com/datasets/rohanrao/air-quality-data-in-india

## 🚀 How to Use
1. Clone or download this repository.
2. Open the `.pbix` file using Microsoft Power BI Desktop.
3. If prompted, update the CSV data source path.
4. Explore the dashboard using the interactive filters.
